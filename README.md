# 万灵驭手 OmniMaster

下一代智能文件管理器，专为 Android 打造。

## 下载安装

| 渠道 | 链接 |
|------|------|
| 官网 | [omnimaster.windgraham.art](https://omnimaster.windgraham.art) |
| GitHub Releases | [Latest Release](../../releases/latest) |

**系统要求：** Android 8.0 及以上

## 核心功能

- 📁 **多窗口文件管理** - 拖拽操作，支持本地/SSH/FTP/SFTP
- 🤖 **AI 智能助手** - DeepSeek 引擎，自然语言管理文件
- 💻 **内置终端** - Python 脚本执行，SSH 客户端
- 🔌 **插件生态** - VSCode 兼容，无限扩展
